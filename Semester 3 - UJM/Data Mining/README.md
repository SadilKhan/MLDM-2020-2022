# Exams

There were two exams, a practical one and a theory exam.

## Practical

The practical exam was worth 33% I think, we had 30 mins to complete Christine's section, and 30 mins (I think) to complete Baptiste's section. They only gave us one exam after we completed the other one.

Christine's part was first, just a very simple MCQ with basic questions about the course content.

Baptiste's part was to hand code some Spark MapReduce problems. If you put the time into the tutorials on Spark, then these questions are mostly not too difficult. (**Baptiste's exam in `exams` folder**)

## Theory

This exam was 2hrs long, and we were given the papers for both Christine and Baptiste at the beginning. So we could decide how much time to give to each subject (unlike with the practical exam).

These exams are also in the `exams` folder.
